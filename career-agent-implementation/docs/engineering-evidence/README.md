# Engineering Evidence Index

This directory explains how to use the trace corpus as project evidence rather than just as tests.

- `CAMPAIGN_REPORT.md` — coverage, trace volume and architecture findings.
- `INCIDENTS.md` — failures discovered during implementation/testing, root causes and fixes.
- `INTERVIEW_NOTES.md` — discussion themes linked to specific traces.
- `FIRST_RUN_RESULTS.json` — preserves the initial 9/12 long-campaign result before fixes.
- `metrics.json` — cardinality of the final long-form trace corpus.

Trace data lives in:

- `scenario-traces/` — 18 focused architecture/regression scenarios.
- `engineering-traces/` — 12 longer multi-step engineering journeys.
