# Trace and Transcript Guide

The repository supports two complementary trace modes.

## 1. Deterministic scenario trace pack

```bash
npm run trace:scenarios
```

By default this writes `scenario-traces/`. Override with:

```bash
TRACE_OUT=/path/to/output npm run trace:scenarios
```

The semantic service outputs and task dialogue in these scenarios are recorded outputs generated by GPT-5.6 Sol, not a fake production LLM implementation. They are replayed to make architecture regression deterministic. Production code does not fall back to them.

Each scenario contains:

- `timeline.jsonl`: chronological scenario events.
- `llm-calls.jsonl`: model service request/response pairs used in the replay.
- `snapshots/*.json`: full state snapshots at important boundaries.
- `tasks/*/transcript.jsonl`: complete task conversation.
- `tasks/*/evaluation.json`: independent evaluator result and emitted observations.
- `assertions.json`: semantic acceptance assertions.
- `final-workspace/`: exact persisted workspace after execution.

Read those files in that order to reconstruct the scenario.

## 2. Real Pi/provider online trace

Configure a real Pi provider first, then run:

```bash
CAREER_AGENT_TRACE_LLM=1 npm run trace:online
```

or with local Pi source:

```bash
PI_CODING_AGENT_MODULE=/absolute/path/to/pi/packages/coding-agent/dist/index.js \
CAREER_AGENT_TRACE_LLM=1 \
npm run trace:online
```

Set an explicit destination if desired:

```bash
ONLINE_TRACE_ROOT=/data/career-agent-online-trace npm run trace:online
```

This path does **not** use recorded model outputs. Assessment/Tutor/Interview messages and evaluator outputs come from the configured real Pi provider.

The online workspace retains:

- `runtime/llm-calls.jsonl`: exact structured-model requests and raw responses.
- `runtime/events.jsonl`: runtime events.
- `tasks/*/transcript.jsonl`: Pi AgentSession transcripts.
- `tasks/*/context.json`: curated TaskContext snapshots.
- `tasks/*/result.json`: evaluator outputs.
- `observations/events.jsonl`: observations.
- `observations/amendments.jsonl`: contest/supersede history if any.
- `state/user-model.json`: derived state.

## Privacy

Trace mode intentionally stores model inputs and raw responses. Resume/JD/evidence content can therefore appear verbatim in trace files. Keep trace directories local/private and do not commit them by default.
